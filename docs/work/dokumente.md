# Dokumente und Anträge

Unter **Dokumente** schreibt Ihre Organisation Anträge, Anfragen, Stellungnahmen und alle anderen Texte gemeinsam. Diese Seite erklärt den Weg vom ersten Entwurf bis zur Einreichung.

## Neues Dokument { #neues-dokument }

1. Öffnen Sie **Dokumente** und wählen Sie **Neues Dokument**.
2. Wählen Sie den Dokumenttyp. Ihre Organisation legt die Typen in den Einstellungen fest, etwa Antrag, Anfrage oder Änderungsantrag, jeweils mit eigener Checkliste und der Angabe, ob eine Freigabe nötig ist. Vorlagen und Briefköpfe verwaltet sie dort ebenfalls.
3. Geben Sie einen Arbeitstitel ein und beginnen Sie zu schreiben.

Dokumente lassen sich in Ordnern ablegen. Für Mitglieder ändern Ordner nichts daran, wer ein Dokument sehen darf. Gästen können Sie dagegen ganze Ordner freigeben.

## Wer sieht ein Dokument? { #sichtbarkeit }

Jedes Dokument hat eine Sichtbarkeit, die Sie über **Teilen** ändern:

| Sichtbarkeit | Wer sieht es |
|--------------|--------------|
| Privat | nur Sie |
| Mit bestimmten Personen | ausgewählte Mitglieder, jeweils mit dem Recht zu lesen, zu kommentieren oder zu bearbeiten |
| Gesamte Organisation | alle Mitglieder Ihrer Organisation |

Mit der passenden Berechtigung teilen Sie Dokumente auch mit anderen Organisationen, etwa Koalitionspartnern, oder mit Gästen.

## Gemeinsam schreiben { #gemeinsam-schreiben }

Mehrere Mitglieder können gleichzeitig am selben Dokument arbeiten, Änderungen erscheinen bei allen sofort. Für Mitschreibende gibt es vier Modi: Bearbeiten, Vorschlagen, nur Kommentieren und nur Ansehen.

- **Kommentare** hängen an Textstellen und bündeln die Diskussion am Dokument.
- **Verlauf**: Beim Speichern entstehen Versionen. Ältere Fassungen lassen sich ansehen und bei Bedarf wiederherstellen.
- **Checkliste**: Der Dokumenttyp kann Punkte vorgeben, die vor der Freigabe erledigt sein sollen, etwa „Recherche abgeschlossen“ oder „Abstimmung mit Fraktion“.
- **Aufgaben** lassen sich direkt aus dem Dokument anlegen und Mitgliedern zuweisen.
- **Import**: Einen vorhandenen Text übernehmen Sie per Import aus einer Word- oder PDF-Datei. Absätze, nummerierte Listen und Tabellen bleiben erhalten; gescannte PDFs liest die Texterkennung Seite für Seite (im Import die ersten zehn Seiten).

## Anhänge { #anhaenge }

In der Seitenleiste **Details** laden Sie Anhänge zum Dokument hoch, etwa Karten, Tabellen oder Stellungnahmen. Möglich sind PDF, Office-Dateien und Bilder. Anhänge lassen sich dort auch umbenennen und wieder entfernen. Reichen Sie den Antrag bei der Verwaltung ein, gehen die Anhänge mit.

## Änderungsanträge und Bezug { #bezug }

Ebenfalls unter **Details** legen Sie fest, worauf sich ein Dokument bezieht: auf einen Antrag Ihrer Organisation oder eine Vorlage aus dem Ratsinformationssystem (Bezugsantrag) und auf eine Sitzung (Bezugssitzung). Das Dokument zeigt dann „Änderungsantrag zu …“, und der Bezugsantrag verweist zurück auf seine Änderungsanträge. Legen Sie einen Änderungsantrag neu an, schlägt Work die Sichtbarkeit des Bezugsantrags vor; Sie können sie ändern.

## Status und Freigabe { #status }

Der Status zeigt, wo ein Dokument steht. Der übliche Weg:

Entwurf → Interne Absprache → Externe Absprache → Freigegeben → Eingereicht → Bei Verwaltung → Auf Tagesordnung → Beschlossen bzw. Erledigt

Die externe Absprache, etwa mit Koalitionspartnern, ist optional. Ein Dokument kann auch abgelehnt, zurückgezogen oder archiviert werden. Welche Schritte vom aktuellen Status aus möglich sind, zeigt der Editor.

Mit **Freigabe anfordern** bitten Sie Mitglieder mit Freigabe-Berechtigung, das Dokument zu prüfen. Diese erteilen oder verweigern die Freigabe, und Sie werden benachrichtigt.

!!! info "Text ab der Freigabe gesperrt"
    Bearbeiten lässt sich ein Dokument nur als Entwurf und in der internen oder externen Absprache. Ab „Freigegeben“ ist der Text eingefroren, damit genau die abgestimmte Fassung eingereicht wird. Nur Mitglieder, die alle Dokumente bearbeiten dürfen, können dann noch ändern.

## Der KI-Assistent { #ki-assistent }

Ist der KI-Assistent für Ihre Organisation eingeschaltet, erscheint im Editor ein eigener Bereich. Er kann:

- markierten Text **verbessern** und umformulieren
- Stichpunkte **ausformulieren**
- das Dokument **prüfen**, etwa auf fehlende Bestandteile eines Antrags
- Titel vorschlagen und Zusammenfassungen erstellen
- Fragen zum Dokument im Chat beantworten

Vorschläge übernehmen Sie erst, wenn Sie auf **Übernehmen** klicken. Die Verantwortung für den Text bleibt bei Ihnen. Ob der Assistent zur Verfügung steht und in welchem Umfang, entscheidet Ihre Organisation.

## Exportieren und einreichen { #einreichen }

- **Export**: Unter **Exportieren** laden Sie das Dokument als PDF oder Word-Datei herunter, mit dem Briefkopf Ihrer Organisation.
- **Digitale Einreichung**: Nutzt Ihre Verwaltung mandari Session, reichen Sie Anträge direkt aus dem Dokument ein und verfolgen den Stand bis zur Beratung. Die Einrichtung beschreibt [Anträge digital einreichen](antraege-einreichen.md).
- **Einreichung per E-Mail**: Ohne Verbindung zu mandari Session reichen Sie über **Bei Verwaltung einreichen** und dann **Per E-Mail einreichen** ein. Der Antrag geht als PDF mit seinen Anhängen an die Verwaltungskontakte, die Ihre Organisation unter *Einstellungen → Ratsfraktionen* pflegt. Im Dokument steht danach, wer wann an wen eingereicht hat; jede Empfängerin und jeder Empfänger kann den Eingang über einen Link in der Mail bestätigen.
- **Klassische Einreichung**: Sonst reichen Sie den exportierten Antrag auf dem Weg ein, den Ihre Kommune vorsieht.

## Tipps { #tipps }

- Diskutieren Sie strittige Anträge früh im Dokument selbst, statt Fassungen per E-Mail hin und her zu schicken.
- Setzen Sie den Status konsequent. Dann sieht jede und jeder auf dem Dashboard und in der Dokumentliste, was gerade ansteht.
