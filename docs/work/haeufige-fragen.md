# Häufige Fragen zu Work

## Konto und Anmeldung

### Wie ändere ich meinen Namen oder mein Profilbild? { #profil-bearbeiten }

Unter *Profil* ändern Sie Vorname, Nachname, Telefonnummer und Profilbild und speichern mit **Speichern**. Was andere Mitglieder von Ihnen sehen, etwa E-Mail-Adresse oder Telefonnummer, legen Sie unter *Profil → Sichtbarkeit* fest. Mehr unter [Erste Schritte](erste-schritte.md#profil).

### Kann ich meine E-Mail-Adresse ändern? { #email-aendern }

Nicht selbst, denn die Adresse ist zugleich Ihr Anmeldename. Wenden Sie sich an den Support.

### Ich habe mein Passwort vergessen. { #passwort-vergessen }

Wählen Sie auf der Anmeldeseite „Passwort vergessen“. Sie bekommen einen Link, über den Sie ein neues Passwort festlegen. Siehe [Konto und Sicherheit](konto-und-sicherheit.md#passwort).

### Ich habe mein Smartphone mit der Authenticator-App verloren. { #smartphone-verloren }

Melden Sie sich mit einem Ihrer Backup-Codes an und richten Sie die App auf dem neuen Gerät neu ein. Ohne Backup-Codes hilft der Support weiter. Siehe [Kein Zugriff mehr auf die App?](konto-und-sicherheit.md#zwei-faktor-verloren)

### Mein Einladungslink funktioniert nicht. { #einladung }

Einladungen sind sieben Tage gültig und nur für die eingeladene E-Mail-Adresse. Melden Sie sich mit genau dieser Adresse an. Ist der Link abgelaufen, bitten Sie die Person, die Sie eingeladen hat, die Einladung erneut zu senden.

### Ich habe mich registriert, komme aber nicht hinein. { #registrierung }

Viele Organisationen schalten neue Registrierungen erst nach einer Prüfung frei. Sie bekommen eine E-Mail, sobald Ihr Zugang freigeschaltet ist. Haben Sie die Bestätigungsmail nicht bekommen, sehen Sie im Spam-Ordner nach. Der Bestätigungslink ist 48 Stunden gültig.

## Arbeiten in Work

### Warum sehe ich bestimmte Sitzungen nicht? { #sitzungen-fehlen }

Meist zeigt die Liste nur Ihre Gremien, oder der Zeitfilter steht auf „Anstehend“. Ihre Gremien sind die unter *Profil → Meine Gremien* ausgewählten, ohne Auswahl die Ihnen zugewiesenen. Die möglichen Gründe und was Sie tun können, stehen unter [Warum sehe ich eine Sitzung nicht?](sitzungen-vorbereiten.md#sitzung-fehlt)

### Wer sieht meine Notizen? { #notizen }

Das hängt vom Bereich ab. Private Notizen zu einem Tagesordnungspunkt sehen nur Sie. Positionen, Diskussionen und geteilte Redebeiträge sehen alle Mitglieder Ihrer Organisation. Dokumente haben eine eigene Sichtbarkeit: privat, für ausgewählte Personen oder für die ganze Organisation. Nach außen, also in das öffentliche Bürgerportal, gelangt nichts davon.

### Warum fehlt mir ein Menüpunkt oder eine Schaltfläche? { #berechtigungen }

Was Sie sehen, richtet sich nach Ihren Rollen und Berechtigungen in der Organisation. Unter *Profil → Anträge* können Sie eine andere Rolle, weitere Gremien oder zusätzliche Berechtigungen beantragen. Die Verwaltung Ihrer Organisation entscheidet darüber.

### Wie bekomme ich die Termine in meinen Kalender? { #kalender }

Unter *Profil* erzeugen Sie einen persönlichen Kalender-Feed (iCal). Er enthält Ihre Fraktionssitzungen aus allen Ihren Organisationen und die Sitzungen Ihrer zugewiesenen Gremien, jeweils nur mit Titel, Zeit und Ort. Die Adresse wird nur einmal angezeigt. Behandeln Sie sie wie ein Passwort. Wer sie kennt, sieht Ihre Termine.

### Wie teile ich unsere Termine auf der Webseite der Fraktion? { #webseite }

Über die öffentliche Fraktions-API. Die Anleitung steht unter [Termine auf der eigenen Webseite](termine-einbinden.md).

### Wo sehe ich, was sich in Work geändert hat? { #neuigkeiten }

Unter [Was ist neu in Work](was-ist-neu.md), neueste Änderungen zuerst.

## Geräte

### Kann ich Work auf dem Smartphone nutzen? { #mobil }

Ja. Work passt sich an Smartphone und Tablet an und lässt sich wie eine App auf dem Startbildschirm installieren. Wie das geht, steht unter [Auf Smartphone und Tablet](erste-schritte.md#mobil). Eine eigene App aus dem App Store brauchen Sie nicht.

### Welche Browser werden unterstützt? { #browser }

Work ist für aktuelle Versionen von Firefox, Chrome, Edge und Safari gebaut. In veralteten Browsern können einzelne Funktionen fehlen, etwa die Anmeldung mit Sicherheitsschlüssel. Halten Sie Ihren Browser schon aus Sicherheitsgründen aktuell.

## Support

### Wie erreiche ich den Support? { #support }

Im Bereich **Support** in Work erstellen Sie ein Ticket und verfolgen die Antworten. Beschreiben Sie, was Sie tun wollten, was stattdessen passiert ist und auf welcher Seite. Screenshots können Sie anhängen. Kommen Sie gar nicht mehr in Work hinein, schreiben Sie an <support@mandari.de>.
