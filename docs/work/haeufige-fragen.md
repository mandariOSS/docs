# Häufige Fragen zu Work

## Konto und Anmeldung

### Wie ändere ich meinen Namen oder mein Profilbild? { #profil-bearbeiten }

Unter *Profil* änderst du Vorname, Nachname, Telefonnummer und Profilbild und speicherst mit **Speichern**. Was andere Mitglieder von dir sehen, etwa E-Mail-Adresse oder Telefonnummer, legst du unter *Profil → Sichtbarkeit* fest. Mehr unter [Erste Schritte](erste-schritte.md#profil).

### Kann ich meine E-Mail-Adresse ändern? { #email-aendern }

Nicht selbst, denn die Adresse ist zugleich dein Anmeldename. Wende dich an den Support.

### Ich habe mein Passwort vergessen. { #passwort-vergessen }

Wähle auf der Anmeldeseite „Passwort vergessen“. Du bekommst einen Link, über den du ein neues Passwort festlegst. Siehe [Konto und Sicherheit](konto-und-sicherheit.md#passwort).

### Ich habe mein Smartphone mit der Authenticator-App verloren. { #smartphone-verloren }

Melde dich mit einem deiner Backup-Codes an und richte die App auf dem neuen Gerät neu ein. Ohne Backup-Codes hilft der Support weiter. Siehe [Kein Zugriff mehr auf die App?](konto-und-sicherheit.md#zwei-faktor-verloren)

### Mein Einladungslink funktioniert nicht. { #einladung }

Einladungen sind sieben Tage gültig und nur für die eingeladene E-Mail-Adresse. Melde dich mit genau dieser Adresse an. Ist der Link abgelaufen, bitte die Person, die dich eingeladen hat, die Einladung erneut zu senden.

### Ich habe mich registriert, komme aber nicht hinein. { #registrierung }

Viele Organisationen schalten neue Registrierungen erst nach einer Prüfung frei. Du bekommst eine E-Mail, sobald dein Zugang freigeschaltet ist. Hast du die Bestätigungsmail nicht bekommen, sieh im Spam-Ordner nach. Der Bestätigungslink ist 48 Stunden gültig.

## Arbeiten in Work

### Warum sehe ich bestimmte Sitzungen nicht? { #sitzungen-fehlen }

Meist zeigt die Liste nur deine Gremien, oder der Zeitfilter steht auf „Anstehend“. Deine Gremien sind die unter *Profil → Meine Gremien* ausgewählten, ohne Auswahl die dir zugewiesenen. Die möglichen Gründe und was du tun kannst, stehen unter [Warum sehe ich eine Sitzung nicht?](sitzungen-vorbereiten.md#sitzung-fehlt)

### Wer sieht meine Notizen? { #notizen }

Das hängt vom Bereich ab. Private Notizen zu einem Tagesordnungspunkt siehst nur du. Positionen, Diskussionen und geteilte Redebeiträge sehen alle Mitglieder deiner Organisation. Dokumente haben eine eigene Sichtbarkeit: privat, für ausgewählte Personen oder für die ganze Organisation. Nach außen, also in das öffentliche Bürgerportal, gelangt nichts davon.

### Warum fehlt mir ein Menüpunkt oder eine Schaltfläche? { #berechtigungen }

Was du siehst, richtet sich nach deinen Rollen und Berechtigungen in der Organisation. Unter *Profil → Anträge* kannst du eine andere Rolle, weitere Gremien oder zusätzliche Berechtigungen beantragen. Die Verwaltung deiner Organisation entscheidet darüber.

### Wie bekomme ich die Termine in meinen Kalender? { #kalender }

Unter *Profil* erzeugst du einen persönlichen Kalender-Feed (iCal). Er enthält deine Fraktionssitzungen aus allen deinen Organisationen und die Sitzungen deiner zugewiesenen Gremien, jeweils nur mit Titel, Zeit und Ort. Die Adresse wird nur einmal angezeigt. Behandle sie wie ein Passwort. Wer sie kennt, sieht deine Termine.

### Wie teile ich unsere Termine auf der Webseite der Fraktion? { #webseite }

Über die öffentliche Fraktions-API. Die Anleitung steht unter [Termine auf der eigenen Webseite](termine-einbinden.md).

## Geräte

### Kann ich Work auf dem Smartphone nutzen? { #mobil }

Ja. Work passt sich an Smartphone und Tablet an und lässt sich wie eine App auf dem Startbildschirm installieren. Wie das geht, steht unter [Auf Smartphone und Tablet](erste-schritte.md#mobil). Eine eigene App aus dem App Store brauchst du nicht.

### Welche Browser werden unterstützt? { #browser }

Work ist für aktuelle Versionen von Firefox, Chrome, Edge und Safari gebaut. In veralteten Browsern können einzelne Funktionen fehlen, etwa die Anmeldung mit Sicherheitsschlüssel. Halte deinen Browser schon aus Sicherheitsgründen aktuell.

## Support

### Wie erreiche ich den Support? { #support }

Im Bereich **Support** in Work erstellst du ein Ticket und verfolgst die Antworten. Beschreibe, was du tun wolltest, was stattdessen passiert ist und auf welcher Seite. Screenshots kannst du anhängen. Kommst du gar nicht mehr in Work hinein, schreib an <support@mandari.de>.
