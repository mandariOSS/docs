# Sitzungen vorbereiten

Unter **Meine Sitzungen** bereitet Ihre Organisation die Sitzungen von Rat, Ausschüssen und Bezirksvertretungen vor. Die Sitzungen und Tagesordnungen kommen automatisch aus dem Ratsinformationssystem der Kommune. Voraussetzung ist, dass Ihre Organisation in den Einstellungen mit ihrer Kommune verknüpft ist.

## Die Sitzungsliste { #sitzungsliste }

Die Liste hat zwei Reiter:

- **Meine Gremien**: Sitzungen der Gremien, die Sie unter *Profil → Meine Gremien* ausgewählt haben. Ohne Auswahl gelten die Gremien, die Ihnen Ihre Organisation zugewiesen hat. Mit Auswahl zählen nur die ausgewählten. Es ist dieselbe Auswahl wie auf dem Dashboard.
- **Alle Sitzungen**: alle Sitzungen der verknüpften Kommune

Haben Sie keine Gremien ausgewählt und auch keine zugewiesen bekommen, zeigt der Reiter „Meine Gremien“ einen Hinweis und darunter alle Sitzungen.

Filter grenzen nach Gremium, Zeitraum (anstehend, vergangen, alle) und Suchbegriff ein. Angezeigt werden Sitzungen aus einem Fenster von rund sechs Monaten in die jeweilige Richtung. Daneben gibt es eine Kalenderansicht.

## Eine Sitzung vorbereiten { #vorbereitung }

Die Vorbereitung gilt für die ganze Organisation: Alle Mitglieder sehen denselben Stand und arbeiten gemeinsam daran. Zu jedem Tagesordnungspunkt gibt es fünf Bereiche.

### Position { #position }

Die gemeinsame Haltung Ihrer Organisation zum Tagesordnungspunkt:

| Position | Bedeutung |
|----------|-----------|
| Noch offen | noch nicht festgelegt |
| Zustimmung, Ablehnung, Enthaltung | Ihr geplantes Abstimmungsverhalten |
| Vertagen, Verweisen | Sie wollen die Entscheidung verschieben oder in ein anderes Gremium geben |
| Mit Änderungsantrag | Zustimmung nur mit eigenem Änderungsantrag |
| Kenntnisnahme | reine Information, keine Abstimmung |

Eine kurze Begründung erklärt die Position für alle Mitglieder. Ist die Position abgestimmt, markieren Sie sie als endgültig. Nach der Sitzung halten Sie das Ergebnis der Beratung fest, etwa „Wie unsere Position“, „Angenommen“ oder „Vertagt“.

### Private Notizen { #private-notizen }

Nur für Sie sichtbar: Argumente, offene Fragen, Erinnerungen. Niemand sonst in der Organisation kann sie lesen.

### Redebeitrag { #redebeitrag }

Bereiten Sie hier vor, was Sie in der Sitzung sagen möchten. Der Beitrag ist zunächst privat. Sie können ihn mit der Organisation teilen, damit andere ihn gegenlesen können.

### Diskussion { #diskussion }

Der Austausch der Organisation zum Tagesordnungspunkt. Gehört eine Vorlage dazu, hängen die Kommentare an der Vorlage selbst. Sie begleiten die Vorlage dann durch alle Gremien, in denen sie beraten wird: Was im Ausschuss diskutiert wurde, steht bei der Ratssitzung wieder bereit.

### Dokumente { #dokumente }

Ergänzende Unterlagen zum Tagesordnungspunkt: Links, hochgeladene Dateien oder Verweise auf Dokumente aus dem Ratsinformationssystem.

## Warum sehe ich eine Sitzung nicht? { #sitzung-fehlt }

- **Reiter „Meine Gremien“**: Er zeigt nur die Sitzungen Ihrer Gremien. Das sind die Gremien, die Sie unter *Profil → Meine Gremien* ausgewählt haben, ohne Auswahl die Ihnen zugewiesenen. Nehmen Sie das Gremium in Ihre Auswahl auf oder wechseln Sie zu „Alle Sitzungen“.
- **Zeitraum**: Vergangene Sitzungen erscheinen erst mit dem Filter „Vergangen“ oder „Alle“.
- **Noch nicht veröffentlicht**: Sitzungen erscheinen, sobald die Kommune sie in ihrem Ratsinformationssystem veröffentlicht hat und mandari sie abgeholt hat. Das geschieht regelmäßig, aber nicht in Echtzeit.
- **Keine Kommune verknüpft**: Dann bleibt die Liste leer, und ein Hinweis führt zu den Einstellungen der Organisation.

Fehlt eine veröffentlichte Sitzung dauerhaft, schreiben Sie ein Ticket im Bereich **Support**. Nennen Sie das Gremium und das Datum der Sitzung.

## Tipps { #tipps }

- Beginnen Sie früh: Tagesordnungen und Vorlagen stehen meist eine Woche vor der Sitzung im Ratsinformationssystem.
- Legen Sie Positionen gemeinsam fest, zum Beispiel in einer [Fraktionssitzung](index.md), und markieren Sie sie dann als endgültig.
- Wer eine Vorlage verfolgen möchte, findet ihre Beratungsfolge und späteren [Beschlüsse](beschluesse.md) unter *Ratsinformation*.
