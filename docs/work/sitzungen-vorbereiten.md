# Sitzungen vorbereiten

Unter **Meine Sitzungen** bereitet eure Organisation die Sitzungen von Rat, Ausschüssen und Bezirksvertretungen vor. Die Sitzungen und Tagesordnungen kommen automatisch aus dem Ratsinformationssystem der Kommune. Voraussetzung ist, dass eure Organisation in den Einstellungen mit ihrer Kommune verknüpft ist.

## Die Sitzungsliste { #sitzungsliste }

Die Liste hat zwei Reiter:

- **Meine Gremien**: Sitzungen der Gremien, die dir deine Organisation zugewiesen hat
- **Alle Sitzungen**: alle Sitzungen der verknüpften Kommune

Filter grenzen nach Gremium, Zeitraum (anstehend, vergangen, alle) und Suchbegriff ein. Angezeigt werden Sitzungen aus einem Fenster von rund sechs Monaten in die jeweilige Richtung. Daneben gibt es eine Kalenderansicht.

## Eine Sitzung vorbereiten { #vorbereitung }

Die Vorbereitung gilt für die ganze Organisation: Alle Mitglieder sehen denselben Stand und arbeiten gemeinsam daran. Zu jedem Tagesordnungspunkt gibt es fünf Bereiche.

### Position { #position }

Die gemeinsame Haltung eurer Organisation zum Tagesordnungspunkt:

| Position | Bedeutung |
|----------|-----------|
| Noch offen | noch nicht festgelegt |
| Zustimmung, Ablehnung, Enthaltung | euer geplantes Abstimmungsverhalten |
| Vertagen, Verweisen | ihr wollt die Entscheidung verschieben oder in ein anderes Gremium geben |
| Mit Änderungsantrag | Zustimmung nur mit eigenem Änderungsantrag |
| Kenntnisnahme | reine Information, keine Abstimmung |

Eine kurze Begründung erklärt die Position für alle Mitglieder. Ist die Position abgestimmt, markiert ihr sie als endgültig. Nach der Sitzung haltet ihr das Ergebnis der Beratung fest, etwa „Wie unsere Position“, „Angenommen“ oder „Vertagt“.

### Private Notizen { #private-notizen }

Nur für dich sichtbar: Argumente, offene Fragen, Erinnerungen. Niemand sonst in der Organisation kann sie lesen.

### Redebeitrag { #redebeitrag }

Bereite hier vor, was du in der Sitzung sagen möchtest. Der Beitrag ist zunächst privat. Du kannst ihn mit der Organisation teilen, damit andere ihn gegenlesen können.

### Diskussion { #diskussion }

Der Austausch der Organisation zum Tagesordnungspunkt. Gehört eine Vorlage dazu, hängen die Kommentare an der Vorlage selbst. Sie begleiten die Vorlage dann durch alle Gremien, in denen sie beraten wird: Was im Ausschuss diskutiert wurde, steht bei der Ratssitzung wieder bereit.

### Dokumente { #dokumente }

Ergänzende Unterlagen zum Tagesordnungspunkt: Links, hochgeladene Dateien oder Verweise auf Dokumente aus dem Ratsinformationssystem.

## Warum sehe ich eine Sitzung nicht? { #sitzung-fehlt }

- **Reiter „Meine Gremien“**: Er zeigt nur die Gremien, die dir deine Organisation zugewiesen hat. Wechsle zu „Alle Sitzungen“ oder bitte die Verwaltung deiner Organisation, dir das Gremium zuzuweisen. Die Auswahl unter *Profil → Meine Gremien* wirkt auf das Dashboard, nicht auf diesen Reiter.
- **Zeitraum**: Vergangene Sitzungen erscheinen erst mit dem Filter „Vergangen“ oder „Alle“.
- **Noch nicht veröffentlicht**: Sitzungen erscheinen, sobald die Kommune sie in ihrem Ratsinformationssystem veröffentlicht hat und mandari sie abgeholt hat. Das geschieht regelmäßig, aber nicht in Echtzeit.
- **Keine Kommune verknüpft**: Dann bleibt die Liste leer, und ein Hinweis führt zu den Einstellungen der Organisation.

Fehlt eine veröffentlichte Sitzung dauerhaft, schreibe ein Ticket im Bereich **Support**. Nenne das Gremium und das Datum der Sitzung.

## Tipps { #tipps }

- Beginne früh: Tagesordnungen und Vorlagen stehen meist eine Woche vor der Sitzung im Ratsinformationssystem.
- Legt Positionen gemeinsam fest, zum Beispiel in einer [Fraktionssitzung](index.md), und markiert sie dann als endgültig.
- Wer eine Vorlage verfolgen möchte, findet ihre Beratungsfolge und späteren [Beschlüsse](beschluesse.md) unter *Ratsinformation*.
